MODEL NOTES

What does this preview calculate?

Build 2026.11.05.3 · solid collision sections · per-step release checks.

MuJoCo runs contact, friction and object motion in your browser. The gripper approaches along its own Z axis, closes, then applies the selected pull or torque.

Each finger has 8 × 2 coupled sections. Stiffness comes from linear 3D FEM; intermediate slider settings interpolate compliance from 27 FEM samples. The local service can recompute FEM for the current geometry.

The visible finger sections are now the actual convex collision pieces, including the outline and ribs. Both use the same section translations. The carrier also participates in object collisions. A small numerical contact overlap remains possible; the measured peak is reported with each run.

This is a segmented linear model, not full nonlinear FEM. It does not model same-finger self-contact or robot reachability. Formal search uses a different evaluation protocol. Preview forces require independent validation.

Release means displacement above 2 mm or rotation above 10° relative to the hold phase. A test stops at the first physics step that exceeds the release threshold. Force ramps use 10 N/s and torque ramps 0.05 N·m/s. A contact overlap above 0.10 mm invalidates a run. Object height changes the shape; grasp height and offsets change its position relative to the fingers. A sphere becomes an ellipsoid when its height differs from its width. Camera orbit changes only the view; approach controls change the physics.

Left and right finger parameters are independent by default. Link edits only when you want a mirrored pair. A search candidate is an archived experiment, not a claim of optimality.
